ეს პროექტი წარმოადგენს თანამედროვე, ასაკობრივად ადაპტირებულ, ინკლუზიურ და ინტერაქტიულ სასწავლო რესურსს საქართველოს სკოლების IV–VI კლასის მოსწავლეებისა და კომპიუტერული ტექნოლოგიების მასწავლებლებისთვის.

შექმნილია წყარო-მასალის (`22.ალგორითმი.docx`) საფუძველზე, ეროვნული სასწავლო გეგმის სტანდარტების სრული დაცვით.

1. გახსენით ფაილი `index.html` ნებისმიერ ბრაუზერში (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari):

## 🌟 აპლიკაციის ძირითადი მოდულები და ფუნქციონალი

### 1. შესავალი და ალგორითმის თვისებები
* **რა არის ალგორითმი:** მარტივი და გასაგები ახსნა დონალდ კნუტის 1968 წლის განმარტებით;
* **ყოველდღიური სცენარები:** სენდვიჩის მომზადება, ქუჩაზე უსაფრთხოდ გადასვლა;
* **ალგორითმის 5 ჯადოსნური თვისება:**
  * ⏳ **სასრულობა** (Finiteness)
  * 🎯 **განსაზღვრულობა / დეტერმინირებულობა** (Definiteness)
  * 🌍 **უნივერსალურობა** (Universality)
  * 🏁 **შედეგიანობა** (Effectiveness)
  * 🪜 **დისკრეტულობა** (Discreteness)
* ინტერაქტიული საინფორმაციო ბარათები „რა მოხდებოდა, ეს თვისება რომ არ ყოფილიყო?“.

### 2. ჩაწერის ფორმები და ენების კიბე
* **სიტყვიერი ფორმა:** ყოველდღიური სასაუბრო ენით ჩაწერილი წესები;
* **ფსევდოკოდი:** სტრუქტურირებული საფეხურები (`თუ... მაშინ... თუ არა...`);
* **ბლოკ-სქემა (ყველა ფიგურა დოკუმენტიდან):**
  * ოვალური (დასაწყისი / დასასრული);
  * პარალელოგრამი (შეტანა / გამოტანა);
  * მართკუთხედი (მოქმედება);
  * რომბი (პირობა / IF გადაწყვეტა);
  * ექვსკუთხედი (მოდიფიკაცია / ციკლი);
  * ორმაგხაზიანი მართკუთხედი (ქვეპროგრამა / წინასწარ განსაზღვრული პროცესი);
  * ტალღოვანი ფიგურა (დოკუმენტი / პრინტერზე დაბეჭდვა).
* **პროგრამირების ენების პირამიდა:**
  * ზედა დონე (Scratch, Python);
  * შუალედური დონე (C, Java, C++);
  * ქვედა დონე (ასემბლერი და მანქანური ორობითი კოდი).

### 3. ალგორითმის ტიპები და ცოცხალი სიმულატორი
* **წრფივი (Linear):** თანმიმდევრული ბიჯები;
* **განშტოებადი (Branching):** პირობის შემოწმება და გზის არჩევა;
* **ციკლური (Loop):** მოქმედების გამეორება პირობის დაკმაყოფილებამდე;
* **რეკურსიული (Recursion):** ბავშვებისთვის ინტუიციური მეტაფორა (ჯადოსნური მატრიოშკა).
* **⚡ ცოცხალი ინტერაქტიული სიმულატორი:** მოსწავლე წერს რიცხვებს A და B, და აკვირდება SVG ბლოკ-სქემაში მანათობელი იმპულსის ნაბიჯ-ნაბიჯ მოძრაობას!

### 4. ინტერაქტიული ლაბორატორია & მინი-თამაშები
* **თამაში 1 (ნაბიჯების დალაგება):** ისრებით საფეხურების სწორი თანმიმდევრობით გადანაწილება;
* **თამაში 2 (ფიგურების ამოცნობა):** ბლოკ-სქემის სიმბოლოების ვიქტორინა;
* **თამაში 3 (დიდი ტესტი):** დიფერენცირებული ქვიზი 2 დონით (დამწყები IV-V კლასისთვის და ექსპერტი V-VI კლასისთვის), მყისიერი წამახალისებელი უკუკავშირითა და ბაგების მეგობრული ახსნით.

### 5. სერტიფიკატი & აღიარება
* პერსონალური სიგელი: **„ახალგაზრდა ალგორითმიკოსი“**;
* მოსწავლეს შეუძლია შეიყვანოს თავისი სახელი და პირდაპირ ბრაუზერიდან დაბეჭდოს ან შეინახოს PDF ფაილად.
