ალგორითმი არის მოქმედებათა ზუსტი, თანმიმდევრული და სრული გეგმა (ნაბიჯების ერთობლიობა), რომლის შესრულებაც აუცილებლად მიგვიყვანს დასახულ შედეგამდე ან ამოხსნის კონკრეტულ ამოცანას.

„ალგორითმი არის ამოცანის ამოხსნისთვის საჭირო მოქმედებათა თანმიმდევრობის განმსაზღვრელი წესები.“ (1968 წ.)

მაგალითი: კიბეზე ასვლისას თითოეულ საფეხურზე რიგრიგობით ვაბიჯებთ.

წარმოიდგინე, დედამ რომ გითხრას: „დაალაგე ოთახი და მერე ითამაშე“. თუ დალაგების პროცესი არასოდეს დასრულდება, თამაშს ვერასოდეს დაიწყებ! ალგორითმში ყოველი მოქმედება მიდის დასასრულისკენ.

ალგორითმიკა და ინფორმატიკა — როგორ უკავშირდებიან ისინი ერთმანეთს?

ინფორმატიკა არის მეცნიერება ინფორმაციის მიღების, დამუშავების, შენახვისა და გადაცემის შესახებ. კომპიუტერები მართულია პროგრამებით, ხოლო ნებისმიერი პროგრამის გული და ძრავა სწორედ ალგორითმია!

✍️

როგორ შეიძლება ჩავწეროთ ალგორითმი?

სიტყვებიდან და ფსევდოკოდიდან ბლოკ-სქემებამდე და პროგრამირებამდე

ერთსა და იმავე ალგორითმს შეგვიძლია რამდენიმე განსხვავებული ფორმით მივცეთ სახე, იმის მიხედვით, თუ ვისთვის არის ის განკუთვნილი — ადამიანისთვის თუ კომპიუტერისთვის:

🗣️

1. სიტყვიერი ჩაწერა (ბუნებრივი ენა)

ალგორითმი იწერება ჩვეულებრივი სასაუბრო ქართული ენით, ნაბიჯ-ნაბიჯ:

ორ რიცხვს შორის უდიდესის პოვნა:
1. განსაზღვრეთ ორი რიცხვი: a და b.
2. შეადარეთ ისინი: თუ a ტოლია b-სი, მაშინ თქვით „რიცხვები ტოლია“.
3. თუ a მეტია b-ზე, უდიდესია a, წინააღმდეგ შემთხვევაში — b.
4. გამოიტანეთ უდიდესი რიცხვი.
📋

2. ფსევდოკოდი (ნახევრად პროგრამული)

აღნიშვნებისა და წესების ერთიანი სისტემა, რომელიც ჰგავს პროგრამირებას, მაგრამ ადვილად წასაკითხია:

შეტანა a, b
თუ a = b მაშინ გამოტანა("რიცხვები ტოლია")
თუ a > b მაშინ გამოტანა(a)
  თუ არა გამოტანა(b)
დასასრული
📐

3. გრაფიკული ჩაწერა — ბლოკ-სქემა

გეომეტრიული ფიგურები, რომლებიც ალგორითმს ნახატად აქცევენ (დააკლიკე ფიგურას გასაცნობად!)

ბლოკ-სქემაში თითოეულ მოქმედებას თავისი უნიკალური გეომეტრიული ფიგურა შეესაბამება:

ოვალური ბლოკი

აღნიშნავს ალგორითმის დაწყებას ან დასრულებას. ნებისმიერი ბლოკ-სქემა ამით იწყება და მთავრდება!

პარალელოგრამი

მონაცემების შემოტანა კომპიუტერში (კლავიატურიდან) ან შედეგის ეკრანზე გამოტანა.

მართკუთხედი

გამოთვლები, მათემატიკური ოპერაციები და ნებისმიერი კონკრეტული მოქმედების შესრულება.

რომბი (პირობა / IF)

ლოგიკური შეკითხვა. გზა ორად იყოფა: „დიახ“ (კი) და „არა“ მიმართულებებად!

ექვსკუთხედი (მოდიფიკაცია)

გამოიყენება ციკლებისთვის: საწყისი მნიშვნელობა, პირობა და ბიჯის გაზრდა (მაგ. i=1-დან 10-მდე).

წინასწარ განსაზღვრული

დამხმარე ალგორითმები ან უკვე მზა ქვეპროგრამები და ფუნქციები, რომელთაც მზა სახით ვიძახებთ.

დოკუმენტის ბლოკი

ტალღოვანი კიდით! მიუთითებს, რომ შედეგი უნდა დაიბეჭდოს ფურცელზე პრინტერის საშუალებით.

🏗️

4. პროგრამირების ენები და კომპიუტერის „ტვინი“

როგორ გადაითარგმნება ალგორითმი კომპიუტერისთვის გასაგებ ენაზე?

კომპიუტერი სინამდვილეში მხოლოდ ელექტრონულ სიგნალებს — 0-ებსა და 1-ებს (ორობით კოდს) აღიქვამს. იმისათვის, რომ ადამიანმა ადვილად დაწეროს პროგრამა, შექმნილია პროგრამირების ენების სხვადასხვა დონე:

🟢

ზედა დონე (High-Level) — ადამიანისთვის ყველაზე მარტივი

ეს ენები ძალიან ჰგავს ბუნებრივ ინგლისურ ენასა და მათემატიკას. მასში წერა მარტივი და სახალისოა!

Scratch (ვიზუალური) Python Pascal Basic Ada
🟡

შუალედური დონე (Mid-Level) — ძლიერი და სწრაფი

აერთიანებს როგორც ადამიანისთვის გასაგებ ბრძანებებს, ასევე პირდაპირ წვდომას კომპიუტერის მეხსიერებასთან.

C C++ C# Java
🔴

ქვედა დონე და მანქანური ენა (Low-Level & Machine) — კომპიუტერის ენა

ასემბლერი (Assembler) და მანქანური კოდი (0 და 1). ეს არის ენა, რომელსაც უშუალოდ კომპიუტერის პროცესორი ასრულებს უსწრაფესად.

Macro-Assembler Binary Code (01010110)

💻 ორი რიცხვიდან უდიდესის პოვნა C ენაზე (საწყისი მასალიდან):

// მარტივი პროგრამა C ენაზე #include <stdio.h> main() { int a, b; scanf("%d, %d", &a, &b); // შეტანა if (a > b) printf("a"); // თუ a მეტია, გამოვიტანოთ a else printf("b"); // წინააღმდეგ შემთხვევაში - b }
🔀

ალგორითმის ძირითადი ტიპები

სამი მმართველი სტრუქტურა, რომელზეც დგას მსოფლიოს ყველა პროგრამა!

მეცნიერებმა დაამტკიცეს, რომ ნებისმიერი, თუნდაც ყველაზე რთული კომპიუტერული თამაში ან პროგრამა, შეიძლება აიგოს მხოლოდ სამი ძირითადი სტრუქტურით (ხოლო კომპაქტურობისთვის ემატება რეკურსიაც):

➡️ 1. წრფივი ალგორითმი (Linear)

ყველა ბრძანება სრულდება თანმიმდევრულად, ერთი მეორის მიყოლებით, სწორი ხაზით — ყოველგვარი გადახვევის ან განმეორების გარეშე.

მაგალითი ცხოვრებიდან: დილით ადგომა ➡️ პირის დაბანა ➡️ ტანსაცმლის ჩაცმა ➡️ საუზმობა.

🌿 2. განშტოებადი ალგორითმი (Branching / Conditional)

შეიცავს პირობის შემოწმებას (რომბის ბლოკი). პასუხის მიხედვით („კი“ თუ „არა“) ალგორითმი ირჩევს სხვადასხვა გზას.

მაგალითი მასალიდან (დედა სახლშია?):
თუ დედა სახლშია ➡️ ვამზადებთ საშინაო დავალებას.
თუ დედა არ არის სახლში ➡️ გავდივართ ეზოში (არიან მეგობრები? ⚽ კი - ფეხბურთი, არა - საქანელა).

🔄 3. ციკლური ალგორითმი (Loop / Iterative)

გულისხმობს მოქმედებათა მიმდევრობის მრავალჯერად განმეორებას მანამ, სანამ გარკვეული პირობა არ შესრულდება (ან წინასწარ განსაზღვრული რაოდენობით).

მაგალითი მასალიდან: გვაქვს რიცხვი $a$. ყოველ ბიჯზე ვუმატებთ 5-ს ($a = a + 5$), სანამ რიცხვი არ გახდება 35-ზე მეტი! როცა 35-ზე მეტი გახდება, ციკლი წყდება.
🪆

4. რეკურსიული ალგორითმი (Recursion — ჯადოსნური თოჯინა)

გინახავთ ქართული სუვენირი ან ხის თოჯინა (მატრიოშკა), რომელსაც გახსნით და შიგნით ზუსტად ისეთივე, ოღონდ უფრო პატარა თოჯინაა?

რეკურსია არის ალგორითმი, რომელიც საკუთარ თავს იძახებს უფრო მცირე ზომის ამოცანისთვის, სანამ უმარტივეს ბაზისურ საფეხურამდე (ყველაზე პატარა თოჯინამდე) არ მივა! ეს საშუალებას გვაძლევს, რთული ამოცანა ძალიან მოკლედ და კომპაქტურად ჩავწეროთ.

⚡

ცოცხალი სიმულატორი: უდიდესი რიცხვის პოვნა

შეიყვანე რიცხვები და უყურე, როგორ ანათებს ბლოკ-სქემა ნაბიჯ-ნაბიჯ!

💡 სტატუსი: შეიყვანე რიცხვები და დააჭირე „გაშვებას“, რათა იხილო იმპულსის მოძრაობა!

ჯილდოვდება მოსწავლე:

სასწავლო მოდულის „რა არის ალგორითმი?“ წარმატებით დასრულების, ალგორითმის 5 ჯადოსნური თვისების, ბლოკ-სქემების შედგენისა და ლოგიკური ამოცანების უშეცდომოდ გადაჭრისთვის.

თარიღი: 2026 წელი
დონე: კომპიუტერული ტექნოლოგიები (IV-VI კლასი)

რობოტი ალგო & მასწავლებელი

👩‍🏫 მასწავლებლის მეთოდური გზამკვლევი & გაკვეთილის გეგმა

🎯 გაკვეთილის მიზანი და შედეგები (IV-VI კლასები)

გაკვეთილის მიზანია მოსწავლემ გააცნობიეროს ალგორითმის არსი, ამოიცნოს მისი თვისებები რეალურ ცხოვრებაში, შეძლოს მარტივი ალგორითმის სიტყვიერი, ფსევდოკოდური და გრაფიკული (ბლოკ-სქემა) სახით წარმოდგენა და განასხვაოს ძირითადი მმართველი სტრუქტურები (წრფივი, განშტოებადი, ციკლური).

⏱️ 45-წუთიანი გაკვეთილის სტრუქტურა

  • ფაზა 1 (10 წთ) — გამოწვევა & მოტივაცია: ყოველდღიური მაგალითები (სენდვიჩი, ქუჩაზე გადასვლა). კითხვა: „რა მოხდება, თუ ნაბიჯებს ადგილს შევუცვლით?“ რობოტი ალგოს გაცნობა.
  • ფაზა 2 (15 წთ) — კვლევა & აღმოჩენა: ალგორითმის 5 თვისება, ბლოკ-სქემის ძირითადი ფიგურები და ალგორითმის ტიპები (წრფივი, განშტოება, ციკლი, რეკურსიის ინტუიციური მეტაფორა).
  • ფაზა 3 (15 წთ) — ინტერაქტიული პრაქტიკა: სიმულატორის გაშვება რიცხვებით, ნაბიჯების დალაგების თამაში, ფიგურების ამოცნობა და დიფერენცირებული ქვიზი.
  • ფაზა 4 (5 წთ) — შეჯამება & აღიარება: შეცდომების (ბაგების) განხილვა როგორც სწავლის შესაძლებლობა; სერტიფიკატების გენერირება.

🌱 ინკლუზიური მიდგომა & დიფერენცირება

- მოსწავლეებს, რომლებსაც უჭირთ კითხვა, ეხმარებათ ვიზუალური ფერადი ბლოკები, SVG ანიმაცია და აუდიო უკუკავშირი.
- სწრაფი ტემპის მოსწავლეებისთვის გათვალისწინებულია „დონე 2: ექსპერტი“, სადაც ლოგიკური ბლოკ-სქემის ამოხსნა და C ენის კოდის ანალიზია მოცემული.

🛡️ ციფრული ეთიკა & უსაფრთხოება

რესურსი არ აგროვებს მოსწავლის პერსონალურ მონაცემებს, მუშაობს სრულად ლოკალურად და ხელს უწყობს შემოქმედებით, უსაფრთხო და მეგობრულ სასწავლო გარემოს.
